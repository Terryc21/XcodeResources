# Contributing to XcodeResources

Thanks for your interest. This repo collects helpful examples, tools, and guides for Swift and Xcode projects. Corrections, new examples, and suggested additions are all welcome.

## Reporting something that's wrong or outdated

Open an issue using the **Correction** template. Swift and Xcode change often, so version-stamping your correction (which Xcode and Swift you verified on) is especially helpful.

## Suggesting a new guide or example

Open an issue using the **Addition** template. The most useful additions are practical examples that solve real problems, not abstract summaries. A short working code sample beats a long description.

## Asking a question

Open a regular issue if no template fits.

## Contributing directly

1. Fork the repo
2. Create a branch off `main`
3. Add your guide, example, or correction
4. Open a PR describing the change

For new categories or structural rewrites, open an issue first to discuss scope.
